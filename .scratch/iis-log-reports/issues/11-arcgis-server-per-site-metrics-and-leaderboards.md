# 11 — ArcGIS Server per-site metrics and leaderboards

**What to build:** One collapsible sidebar group per Included Root, each expanding into its 8 metrics (successful/failed request-count evolution, successful/failed average-processing-time evolution) and their corresponding Top-50 Leaderboards (by successful hits, failed hits, average time successful, average time failed), each with All/Last-7-Days variants.

**Blocked by:** 10.

**Status:** done

- [x] Exactly the 14 configured Included Roots appear as ArcGIS Server sidebar groups — no others, even when the aggregate database has traffic under additional Roots (verified against the fixture database, which includes the `proxy` Root: it must not appear).
- [x] Each Root group renders its 8 metrics correctly: per-day values, never cumulative; average-time charts recompute per day rather than reusing the hit-count query's rows.
- [x] Each of the 4 Top-50 Leaderboards renders as a `BarChart`, sorted descending by its own measure, with no manufactured secondary tie-break.
- [x] A Root with fewer than 50 services renders a Leaderboard with only as many bars as exist — no placeholder bars (verified against a low-service Root in the fixture, or one deliberately given few services).
- [x] All figures computed on the fly against the aggregate database each run — no precomputed rollup table introduced.
